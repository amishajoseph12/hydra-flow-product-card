💧 Hydra Flow — Product Card

A clean and modern eco-friendly water bottle product card created using HTML and CSS.

This project was created as part of a Product Card Challenge, where the design had to be built using only HTML and CSS while maintaining an exact 400 × 500 px card size.

✨ Features

- 🌿 Eco-friendly product design
- 💧 Hydration-focused branding
- 🛒 Add to Cart button
- 💰 Product pricing and discount display
- 📦 Available bottle sizes
- 🎨 Available colour options
- 🔒 Product feature highlights
- 📱 Responsive display
- 📐 Exact 400 × 500 px product card
- 🎨 Soft cream, sage green and pastel colour palette

🛠️ Technologies Used

- HTML5 — Structure of the product card
- CSS3 — Styling, layout, colours, spacing and responsiveness
- JPEG Images — Product visuals

No JavaScript or external frameworks were used.
